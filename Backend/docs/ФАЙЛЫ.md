# Backend — назначение каждого файла

## Точка входа

| Файл | Назначение | На защите сказать |
|------|------------|-------------------|
| `src/index.js` | Запуск Express, подключение маршрутов, health, статика `/uploads` | «Это главный файл сервера, здесь собирается всё API» |

---

## config/

| Файл | Назначение |
|------|------------|
| `database.js` | Подключение к PostgreSQL через `DATABASE_URL`, SSL для Render |
| `uploadsPath.js` | Пути `uploads/products`, `uploads/scans` |

---

## database/

| Файл | Назначение |
|------|------------|
| `migrate.js` | При старте сервера выполняет все `.sql` из `database/migrations/` |
| `migrations/*.sql` | Пошаговое создание таблиц (users, products, orders, support, scans, rbac…) |

---

## constants/

| Файл | Назначение |
|------|------------|
| `roles.js` | Константы ролей и функции `isAdminRole`, `normalizeRole` |

---

## middleware/

| Файл | Назначение |
|------|------------|
| `auth.js` | Читает JWT из `Authorization`, кладёт `req.user` |
| `rbac.js` | Проверка роли в БД: admin / super-admin |
| `requireAdmin.js` | Реэкспорт `requireAdmin` для маршрутов |
| `upload.js` | Загрузка изображений товаров |
| `uploadScan.js` | Загрузка фото для AI-камеры |
| `validation.js` | Ответ 400 при ошибках валидации |
| `errorHandler.js` | 404 и централизованная обработка ошибок |

---

## routes/ → controllers/ (пары)

| Маршрут `routes/` | Контроллер | Префикс API | Кто может |
|-------------------|------------|-------------|-----------|
| `authRoutes.js` | `authController.js` | `/api/auth` | Все / JWT |
| `entriesRoutes.js` | `entriesController.js` | `/api/entries` | JWT — дневник калорий |
| `waterRoutes.js` | `waterController.js` | `/api/water` | JWT — вода за день |
| `scansRoutes.js` | `scansController.js` | `/api/scans` | JWT — AI-камера |
| `cartRoutes.js` | `cartController.js` + `checkoutController.js` | `/api/cart` | JWT — корзина и оплата |
| `shopRoutes.js` | `shopController.js` | `/api/products` | Публичный каталог магазина |
| `productsRoutes.js` | `productsController.js` | `/api/admin/products` | ADMIN — CRUD товаров |
| `ordersRoutes.js` | `ordersController.js` | `/api/admin/orders` | ADMIN — список/удаление заказов |
| `usersRoutes.js` | `usersController.js` | `/api/admin/users` | ADMIN — пользователи, бан |
| `supportRoutes.js` | `supportController.js` | `/api/support` | USER пишет, ADMIN отвечает |
| `adminWorkoutsRoutes.js` | `workoutsController.js` | `/api/admin/workouts` | ADMIN — тренировки |
| `adminManagementRoutes.js` | `adminManagementController.js` | `/api/admin` | SUPER_ADMIN — админы |
| `adminNotificationsRoutes.js` | `adminNotificationsController.js` | `/api/admin/notifications` | ADMIN — счётчики для бейджей |

### Детали контроллеров

| Контроллер | Что делает |
|------------|------------|
| `authController.js` | Регистрация, вход, JWT, профиль |
| `entriesController.js` | CRUD записей еды, статистика, график |
| `waterController.js` | Вода за сегодня, добавить стакан |
| `scansController.js` | Распознать фото, история сканов, добавить в дневник |
| `cartController.js` | Корзина: список, добавить, изменить qty |
| `checkoutController.js` | Оформление заказа из корзины |
| `shopController.js` | Список товаров для витрины |
| `productsController.js` | Админ: создать/изменить/удалить товар + фото |
| `ordersController.js` | Админ: все заказы с позициями |
| `usersController.js` | Админ: список, бан, удаление |
| `supportController.js` | Обращения: создать, список, статус, ответ |
| `workoutsController.js` | Список тренировок (публичный GET в index) + админ CRUD |
| `adminManagementController.js` | Создать/удалить админа, сменить пароль |
| `adminNotificationsController.js` | `counts` — числа для красных бейджей в шапке |

## services/vision/ (AI-камера)

| Файл | Назначение |
|------|------------|
| `index.js` | Оркестратор: выбор провайдера, вызов анализа |
| `resolveProvider.js` | `auto` / `local` / `openai` / `gemini` |
| `LocalVisionAdapter.js` | Локальная модель CLIP (Transformers.js) |
| `OpenAIVisionAdapter.js` | GPT-4 Vision |
| `GeminiVisionAdapter.js` | Google Gemini |
| `MockVisionAdapter.js` | Заглушка для тестов |
| `foodCatalog.js` | Список блюд и категорий для сопоставления |
| `localRanker.js` | Двухэтапное ранжирование CLIP |
| `visionPrompt.js` | Текст промпта для облачных моделей |
| `parseVisionResponse.js` | Разбор JSON ответа LLM |
| `loadImageInput.js` | Подготовка буфера изображения |
| `visionErrors.js` | Коды ошибок vision |
| `warmup.js` | Прогрев модели при старте |
| `types.js` | JSDoc-типы |
