# Полная структура проекта Calorie Tracker Pro

## Корень `Diplomka/`

| Файл / папка | Назначение |
|--------------|------------|
| `Backend/` | Сервер API |
| `Front end/` | Клиент React |
| `docs/` | Документация для защиты |
| `docker-compose.yml` | Опциональный запуск всего стека |
| `DOCKER.md` | Инструкции Docker |

---

## Backend

| Путь | Назначение |
|------|------------|
| `src/index.js` | **Главный файл сервера** — Express, CORS, все `app.use('/api/...')` |
| `src/config/database.js` | Пул подключений к PostgreSQL |
| `src/config/uploadsPath.js` | Пути к папкам загрузок |
| `src/database/migrate.js` | Автомиграции при старте |
| `src/constants/roles.js` | Роли USER / ADMIN / SUPER_ADMIN |
| `src/middleware/auth.js` | JWT: `authenticateToken`, `requireAuth` |
| `src/middleware/rbac.js` | `requireAdmin`, `requireSuperAdmin`, `loadUserRole` |
| `src/middleware/requireAdmin.js` | Реэкспорт RBAC |
| `src/middleware/upload.js` | Multer — фото товаров |
| `src/middleware/uploadScan.js` | Multer — фото для AI-камеры |
| `src/middleware/validation.js` | Ошибки express-validator |
| `src/middleware/errorHandler.js` | 404 и общие ошибки |
| `src/routes/*.js` | Маршруты → контроллеры (см. Backend/docs/ФАЙЛЫ.md) |
| `src/controllers/*.js` | Обработчики запросов |
| `src/services/vision/` | Модуль распознавания еды по фото |
| `database/migrations/` | SQL-миграции схемы БД |
| `database/seed-products.json` | Данные для сидера товаров |
| `scripts/add-admin.js` | Создать супер-админа в БД |
| `scripts/seed-products.js` | Заполнить магазин товарами |
| `docker-compose.yml` | Backend + Postgres (профиль `local-db`) |
| `Dockerfile` | Образ Node + кэш модели CLIP |
| `.env` | Секреты (не в git): DATABASE_URL, JWT, API keys |

## Front end

| Путь | Назначение |
|------|------------|
| `src/main.jsx` | Старт React, ThemeProvider, LanguageProvider |
| `src/App.jsx` | React Router — все URL приложения |
| `src/api/client.js` | **Базовый HTTP-клиент** — fetch + JWT |
| `src/api/*.js` | Методы API по доменам (auth, shop, orders…) |
| `src/pages/*.jsx` | Страницы приложения |
| `src/components/Header.jsx` | Шапка, меню, бейджи админа |
| `src/components/ProtectedRoute.jsx` | Доступ только авторизованным |
| `src/components/AdminRoute.jsx` | Доступ ADMIN / SUPER_ADMIN |
| `src/components/SuperAdminRoute.jsx` | Только SUPER_ADMIN |
| `src/components/AiAssistant.jsx` | Чат-помощник + отправка в поддержку |
| `src/i18n/translations.js` | Тексты ru / kk / en |
| `src/utils/roles.js` | Проверки ролей на клиенте |
| `src/utils/adminNotifications.js` | Счётчики «непросмотренных» для бейджей |
| `vite.config.js` | Dev-сервер + proxy `/api` → :3003 |

Подробно по каждому файлу: [Front end/docs/ФАЙЛЫ.md](../Front%20end/docs/ФАЙЛЫ.md)

## Связь фронт ↔ бэк (примеры)

| Действие пользователя | Фронт | API |
|----------------------|-------|-----|
| Вход | `LoginPage` → `authApi.login` | `POST /api/auth/login` |
| Добавить калории | `MainPage` → `entriesApi` | `POST /api/entries` |
| AI-фото | `AiCameraPage` → `scansApi` | `POST /api/scans/recognize` |
| Корзина | `CartPage` → `shopApi` | `GET/POST /api/cart` |
| Заказ | `CartPage` checkout | `POST /api/cart/checkout` |
| Админ: заказы | `OrdersPage` → `ordersApi` | `GET /api/admin/orders` |
| Бейджи | `Header.jsx` | `GET /api/admin/notifications/counts` |
