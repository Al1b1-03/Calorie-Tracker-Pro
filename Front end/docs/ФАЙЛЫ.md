# Frontend — назначение каждого файла

## Точка входа и каркас

| Файл | Назначение | На защите |
|------|------------|-----------|
| `src/main.jsx` | Запуск React, обёртки темы и языка | «Точка входа SPA» |
| `src/App.jsx` | Все маршруты URL → страницы | «Здесь карта всего приложения» |
| `src/index.css` | Импорт глобальных стилей | — |

---

## api/ — запросы на бэкенд

| Файл | Назначение | API |
|------|------------|-----|
| `client.js` | **Общий fetch**, JWT, базовый URL | — |
| `auth.js` | Вход, регистрация, профиль | `/api/auth/*` |
| `entries.js` | Дневник калорий | `/api/entries/*` |
| `water.js` | Вода | `/api/water/*` |
| `scans.js` | AI-камера | `/api/scans/*` |
| `shop.js` | Магазин, корзина, checkout | `/api/products`, `/api/cart/*` |
| `products.js` | Админ: товары | `/api/admin/products/*` |
| `orders.js` | Админ: заказы | `/api/admin/orders/*` |
| `users.js` | Админ: пользователи | `/api/admin/users/*` |
| `support.js` | Поддержка | `/api/support/*` |
| `workouts.js` | Тренировки | `/api/workouts`, `/api/admin/workouts` |
| `adminManagement.js` | Управление админами | `/api/admin/*` |
| `adminNotifications.js` | Счётчики бейджей | `/api/admin/notifications/counts` |

---

## pages/ — экраны

| Файл | URL | Роль | Назначение |
|------|-----|------|------------|
| `HomePage.jsx` | `/` | USER | Главная: дашборд или редирект админа |
| `MainPage.jsx` | (внутри Home) | USER | Дневник, калории, график |
| `AdminMainPage.jsx` | (внутри Home) | ADMIN | Плитки разделов админки |
| `LoginPage.jsx` | `/login` | — | Вход |
| `RegistrationForm.jsx` | `/registration` | — | Регистрация |
| `ProfilePage.jsx` | `/profile` | USER/ADMIN | Профиль, нормы КБЖУ |
| `AdminProfilePage.jsx` | (в Profile) | ADMIN | Профиль администратора |
| `AboutPage.jsx` | `/about` | Все | О проекте |
| `ProductsShopPage.jsx` | `/shop` | USER | Витрина магазина |
| `CartPage.jsx` | `/cart` | USER | Корзина и оформление |
| `AiCameraPage.jsx` | `/ai-camera` | USER | Фото еды → AI → в дневник |
| `WorkoutsPage.jsx` | `/workouts` | USER | Каталог тренировок |
| `WorkoutsPageRouter.jsx` | `/workouts` | — | USER vs AdminWorkoutsPage |
| `AdminWorkoutsPage.jsx` | `/workouts` | ADMIN | CRUD тренировок |
| `ProductsPage.jsx` | `/products` | ADMIN | Управление товарами |
| `OrdersPage.jsx` | `/orders` | ADMIN | Список заказов |
| `SupportMessagesPage.jsx` | `/support` | ADMIN | Обращения пользователей |
| `UsersPage.jsx` | `/users` | ADMIN | Пользователи, бан |
| `AdminManagementPage.jsx` | `/admin-management` | SUPER_ADMIN | Создание админов |

`.css` рядом с каждой страницей — только стили этой страницы.

## components/ — переиспользуемые блоки

| Файл | Назначение |
|------|------------|
| `Header.jsx` | Логотип, меню, язык, тема, **бейджи заказов/поддержки** |
| `Footer.jsx` | Подвал сайта |
| `ProtectedRoute.jsx` | Нет токена → `/login` |
| `AdminRoute.jsx` | Не админ → домой |
| `SuperAdminRoute.jsx` | Не супер-админ → `/products` |
| `RegistrationForm.jsx` | Форма регистрации |
| `AiAssistant.jsx` | Плавающий чат + отправка в поддержку |
| `dashboard/DashboardSection.jsx` | Блоки на главной |
| `ui/PageHero.jsx` | Заголовок страницы |
| `ui/Skeleton.jsx` | Скелетон загрузки |
| `ui/RingProgress.jsx` | Кольцо прогресса калорий |
| `ui/Toast.jsx` | Всплывающие уведомления |
| `ui/EmptyState.jsx` | Пустой список |

## utils/, hooks/, context/, i18n/

| Файл | Назначение |
|------|------------|
| `utils/roles.js` | `isAdmin`, `isSuperAdmin`, редирект после входа |
| `utils/adminNotifications.js` | localStorage: какие заказы/обращения уже «просмотрены» |
| `utils/calorieCalculator.js` | Расчёт нормы калорий по антропометрии |
| `utils/assistantEngine.js` | Логика ответов AI-помощника на клиенте |
| `utils/prepareImageFile.js` | Сжатие фото перед отправкой на сервер |
| `hooks/useAdminNotificationCounts.js` | (запасной) хук счётчиков — основная логика в Header |
| `hooks/useBodyClass.js` | CSS-класс на body |
| `context/ThemeContext.jsx` | Светлая / тёмная тема |
| `i18n/LanguageContext.jsx` | Язык ru / kk / en |
| `i18n/translations.js` | Все строки интерфейса |
| `i18n/dynamicContent.js` | Перевод названий товаров с бэка |
